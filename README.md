Simulación y análisis de señales con la Transformada de Fourier

Descripción

Este proyecto analiza señales elementales en los dominios del tiempo y de la frecuencia mediante la Transformada Discreta de Fourier utilizando Python.

Objetivo

Representar señales, calcular sus espectros de magnitud y fase, y estudiar propiedades de la Transformada de Fourier.

Señales analizadas

- Señal senoidal de 5 Hz.
- Pulso rectangular.
- Función escalón.

Propiedades estudiadas

- Linealidad.
- Desplazamiento temporal.
- Escalamiento temporal.

Herramientas utilizadas

- Python.
- NumPy.
- Matplotlib.
- Google Colab.

Ejecución

El archivo "transformada_fourier.py" contiene el código utilizado para generar las señales, calcular sus transformadas y visualizar los resultados.

Para ejecutar el programa se requiere un entorno de Python con las bibliotecas NumPy y Matplotlib instaladas.

Resultados

La simulación permite comparar las señales en el dominio del tiempo y sus espectros de frecuencia, así como observar los efectos del desplazamiento y del escalamiento temporal.
